Frequently Asked Questions

Soalan yang sering ditanya mengenai Docs Drizzev.

Apakah Docs Drizzev?

Docs Drizzev ialah laman dokumentasi yang mengumpulkan maklumat mengenai projek dan tools yang dibuat oleh Drizzev.

Apakah projek yang terdapat di sini?

Dokumentasi boleh merangkumi Minecraft addons, plugins, resource pack, tools, API dan projek lain.

Adakah Docs Drizzev untuk Minecraft sahaja?

Tidak semestinya. Minecraft merupakan salah satu fokus utama, tetapi dokumentasi lain boleh ditambah pada masa akan datang.

Adakah dokumentasi ini percuma?

Kandungan dokumentasi boleh disediakan secara percuma mengikut projek dan penggunaannya.

Siapakah yang membangunkan projek Drizzev?

Projek-projek yang dipaparkan dalam dokumentasi ini dibangunkan di bawah nama Drizzev.

Bolehkah lebih banyak dokumentasi ditambah?

Ya. Struktur homepage ini boleh dikembangkan dengan dokumentasi dan projek baharu pada masa akan datang.
