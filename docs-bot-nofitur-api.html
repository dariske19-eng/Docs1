DRIZZEV · BOT NO FITUR API

Dokumentasi Bot No Fitur

API HTTP untuk hantar mesej WhatsApp tanpa command bot. Gaya ringkas seperti Whapi — satu API key, hantar teks ke nombor.

Apa itu Bot No Fitur?

Bot No Fitur ialah jenis bot dalam panel bot.drizzev.web.id yang tidak menjalankan command (.menu, stiker, download, dll.). Ia hanya menyambung WhatsApp dan mendedahkan API key supaya sistem anda boleh hantar mesej melalui HTTP.

Sesuai untuk: notifikasi order, OTP, bot CRM, integrasi website / server sendiri.

Beza Bot Fitur vs Bot No Fitur

Bot FiturBot No Fitur (API)
Command (.menu, dll.)AdaTiada
API keyTidakAda (Console panel)
Hantar mesejDari chat WADari HTTP API
Sambungan QR / PairingYaYa

Mula cepat

  1. Login di panel
  2. Claim kod 6 digit → pilih Bot No Fitur (API)
  3. Buka panel bot → tab Sambungan → QR atau Pairing
  4. Tunggu status running
  5. Tab Console → salin API key
  6. Panggil POST /api/v1/send

Authentication

Setiap request API mesti bawa API key:

Authorization: Bearer drizz_xxxxxxxx...

Atau header alternatif:

X-Api-Key: drizz_xxxxxxxx...
Jangan kongsi API key di tempat awam. Sesiapa yang ada key boleh hantar mesej atas nama bot anda.

POST /api/v1/send

POST {BASE_URL}/api/v1/send

BASE_URL = URL panel, contoh https://bot.drizzev.web.id

Headers

HeaderNilai
AuthorizationBearer <api_key>
Content-Typeapplication/json

Body (JSON)

FieldWajibKeterangan
toYaNombor (contoh 60123456789)
messageYa*Teks mesej
textYa*Alias untuk message

* Salah satu message atau text diperlukan.

Contoh body

{
  "to": "60123456789",
  "message": "Hello dari DrizzEv API"
}

Response berjaya

{
  "ok": true,
  "job_id": "a1b2c3d4e5f6",
  "status": "queued"
}

GET /api/v1/status

GET {BASE_URL}/api/v1/status

Authorization: Bearer drizz_xxxxxxxx...

Response

{
  "ok": true,
  "status": "running",
  "phone": "60123456789",
  "expires_at": "2026-11-24T00:00:00.000Z",
  "mode": "api"
}

Kod ralat

HTTPMaksud
400Body tidak sah
401API key tiada / tidak sah
403Bukan bot API / langganan tamat
503Bot belum online
500Ralat server

Contoh cURL

curl -X POST "https://bot.drizzev.web.id/api/v1/send" \
  -H "Authorization: Bearer drizz_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to":"60123456789","message":"Hello"}'

Contoh JavaScript

const res = await fetch("https://bot.drizzev.web.id/api/v1/send", {
  method: "POST",
  headers: {
    "Authorization": "Bearer drizz_YOUR_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    to: "60123456789",
    message: "Hello dari Node",
  }),
});
const data = await res.json();
console.log(data);

Contoh PHP

$ch = curl_init("https://bot.drizzev.web.id/api/v1/send");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_HTTPHEADER => [
    "Authorization: Bearer drizz_YOUR_KEY",
    "Content-Type: application/json",
  ],
  CURLOPT_POSTFIELDS => json_encode([
    "to" => "60123456789",
    "message" => "Hello dari PHP",
  ]),
  CURLOPT_RETURNTRANSFER => true,
]);
echo curl_exec($ch);

Panel & API key

Selepas claim Bot No Fitur, buka panel → tab Console:

  • API key + butang Salin
  • Contoh request
  • Log aktiviti

Had & nota

  • Bot mesti running sebelum /send berjaya.
  • Nombor to tanpa + (contoh MY: 60…).
  • Versi semasa: hantar teks sahaja.
  • Panel: bot.drizzev.web.id
